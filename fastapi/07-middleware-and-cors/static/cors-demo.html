CORS demo

Serve this file from a different origin than the API, then open it in a browser. From the 07-middleware-and-cors folder: 

python -m http.server 5500 --directory static

Then open http://127.0.0.1:5500/cors-demo.html with the API running on port 8000. 127.0.0.1:5500 is in CORS_ALLOWED_ORIGINS in the shared .env, so requests are allowed. Open the same page via localhost:5500 instead and the requests are blocked - a different hostname is a different origin, even though it is the same machine.
