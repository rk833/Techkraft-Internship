# Getting set up

Request access to the vault first, everything else depends on it. Ask in the
platform channel and expect it to take a working day.

Run the test suite before your first pull request so you know it passes on your
machine. It takes about eleven minutes.

Deployments happen Monday to Thursday. Do not deploy on a Friday without asking
the on call engineer.

The staging database is shared. Do not run destructive migrations against it.
