[work] Standup time changed
The daily standup moves to 09:30 from Monday. The team lead asked everyone to

[work] Postgres connection pool
The API kept dropping requests under load because the connection pool was set
to ten. Raising it to fifty fixed it. Worth checking the pool size first
whenever the service gets slow under traffic.

[work] Code review checklist
Look at error handling before style. Check that failures are logged with enough
context to debug, and that nothing swallows an exception silently.

[study] Cosine similarity
Measures the angle between two vectors and ignores their magnitude. For text
embeddings the direction carries the meaning, so this is preferred over
euclidean distance.

[study] Chunk overlap
Repeating the end of one chunk at the start of the next stops a sentence being
cut in half at a boundary. Ten to twenty percent of chunk size is a reasonable
starting point.

[work] Deploy rollback

[study] Token limits
A model's context window is measured in tokens, not characters. Roughly four
characters per token for English, but this varies by tokenizer.
